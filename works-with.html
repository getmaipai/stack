Apps and tools

Apps that speak the OpenAI format

Stack answers on one local address, 127.0.0.1 port 8770 by default, in the shape existing client libraries use. Chat completions, embeddings, transcription, speech, pictures, video and music each have a standard path. Apps that are not Home can use chat, vision, speech and the model list.

  • Reads such as the model list work as is on this computer.
  • Make an app key on the admin page and send it as a standard bearer key. Each key is limited to the scopes you tick, can be revoked at once, and waits behind Home's own requests.
  • Keys work on this computer only, and do not reach settings, jobs, embeddings or picture routes.
  • No third-party app is tested yet, so none is named.

Engines

Stack starts and watches these for you, so an app asks for a job, not a program. Swapping one never changes the address your apps use.
