# v0.1.0 capability matrix

2026-09-18. This is the release contract for the Mac app. It applies the
capability rule in [`dev.md`](../dev.md#scope-by-what-is-reliable-capability-by-capability-decided-2026-09-18-1045)
to the existing routes, pages, three reviews, backlog, and the temporary-data
[live walk](../dev.md#live-walk-2026-09-18). A route, scripted stand-in, or
showroom capture alone is not release proof. The live walk used a copy of an
existing installation, so **no cell is reliable now on a clean account**.
This is deliberate: the clean-account checks below are release gates, not
claims that the September 18 walk already passed them.

## How to read the cells

Each cell has exactly one status. **R** means **reliable now**, with a cited
clean-account result. **B** means **reliable with bounded work**, followed
by the owning STACK item and live check below. **M** means **monitor only in
v0.1.0**: the release may show observed state but must not offer that
operation; the cell states why. **N** means **not in v0.1.0**; the cell
states why. There are no R cells yet. A B cell becomes R only when its live
check is recorded on a clean account and linked here. The item number alone
is not evidence. The live walk proves the narrower existing-data behavior
of model rename, groups, load, unload, pin, remove, llama start/stop/restart,
client key lifecycle, chat, settings, checks, and Library fetch. It does
not qualify a fresh install, every model kind, or a signed update.

For Library, download/install/update mean explicitly fetched
documentation, never model or engine bytes. For backups, download is a
copy of an encrypted archive and install is a staged restore. For app
uninstall, the acceptance includes the LaunchAgent and documented local
data choice. For settings, update is a value change and uninstall is reset.
These meanings must be shown beside the controls.

## The release a parent can expect

The first release is a Mac app that helps you find a verified model, see
its size and licence, download and install it, organize it, try it, and
remove it when you are done. Chat is the first measured setup; coding and
embedding models join it only after their own clean-account role checks.
The app shows the health of its own engine and any local tools it finds,
helps you give and revoke access to clients, checks for problems, keeps
encrypted state backups, and offers offline Help and a searchable Library.
It can update the app and a qualified model revision after a proven
recovery check. It shows voice, image, video, music, and external engine
status where detected, but does not promise to install, control or update
those hosts yet. Every unavailable action says why.

## Disabled-control inventory

STACK-92 applies this list on desktop and phone. The cited UI locations
are observed in `frontend/src/pages/` and its shared add sheet; C8 checks
the actual built app. One sentence appears beside each disabled control.

| Visible control today | Required sentence |
|---|---|
| Engines Add or Install for mlx-serve, ComfyUI or an unqualified llama build | “This engine has no tested install for this computer yet.” |
| Engines Update, including the row menu and Settings update result | “Engine updates need a tested build and recovery check before they can run here.” |
| Engines Remove for a detected external host | “This tool belongs to another app; Stack can only forget its listing.” |
| Start, Stop, Restart or Configure on a detected host | “This tool runs outside Stack; manage it in its own app.” |
| Model Install or Update on an unresolved, gated, unsupported or non-GGUF result | “This model needs verified files, licence and a tested way to run before installation.” |
| Model Load, Unload or Pin for unqualified voice, image, video or music files | “There is no tested engine for this model here yet.” |
| Tester Voice in Record, Voice out Play | “Voice needs a tested local speech engine before this can run.” |
| Tester Images, Video or Music Generate | “This role needs a tested generation job; no result will be produced yet.” |
| Settings Clear caches | “Cache clearing is not available yet; installed models stay intact.” |
| Phone Add, Search or Group before STACK-82 wiring | “Open the full page to use this action until phone controls are ready.” |
| App or engine “Current” when the manifest is missing, invalid or stale | “Update status is unknown; the last verified check is shown below.” |
| Ask repair action without a cited local source | “I can show matching Help and status, but I cannot verify that repair.” |

This inventory also governs any same-action icon in a model or engine
panel. STACK-82 removes the phone placeholders; STACK-92 removes or
disables the remaining misleading affordances. A disabled state is not
a substitute for a promised B check.
