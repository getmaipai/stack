# Choose features and models

You decide which jobs the Stack does, which model does each job, and who gets memory first when it runs short. It takes about 5 minutes.

## The features

| Feature | What it does |
|---|---|
| Chat | Answers questions in conversation. |
| Coding | A larger model for code. Loads when asked. |
| Judge | A small, fast model for quick answers. |
| Router | Picks which model should answer. |
| Embeddings | Turns text into numbers so it can be searched. |
| Re-rank | Sorts search results by how well they match. |
| Vision | Reads pictures. |
| Voice in | Turns speech into text. |
| Voice out | Turns text into speech. |
| Wake word | Listens for a trigger phrase on a paired device. |
| Images, Video, Music | Make pictures, clips and songs. Load when asked. |
| Helper | The admin page's own assistant. See [the Helper](helper.md). |

## Pick a setup for this computer

1. Open **Models**.
2. Read **Setup for this computer**. It says how much memory your computer has and which setup fits (16, 32, 64 or 128 GB and up).
3. Look at the plan under **Custom, recommended**. Each feature says "Stays in memory" or "Loads when asked", and whether it fits.
4. Click **Use Matched** (the ready-made setup, when one fits), **Use Custom, recommended** (fitted to your memory), or **Keep my own choices** (checked for fit, nothing turned on or off for you). Confirm. The Stack saves the choice and starts the downloads it needs.

The setup is a starting point. You can change any feature after.

## Turn a feature on or off

1. Open **Features**.
2. Use the switch on the card.
3. Confirm. The page tells you what happened in a sentence.

A feature that is off does not start and uses no memory. If someone asks for it, the Stack says it is off.

## Choose a model

1. Open **Models** and scroll to the feature.
2. Each model shows its size and "Not installed" or "Installed". Click **Download** to get it, or **Remove** to delete it.
3. Wait for "Installed". Big models take a while. The page checks every few seconds.

Every download comes from a pinned address and is checked against a checksum before the Stack uses it. The list is the Stack's pinned list. You cannot add your own model from the page yet.

## Set the order

When memory is tight, features wait in line. Under **Models**, the **Priority** list sets who goes first. Use the up and down buttons. The one at the top is served first.
