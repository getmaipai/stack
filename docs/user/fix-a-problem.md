---
title: Fix a problem
description: What to do when a download stops, the board shows red, or a page will not open.
---

## If a download stops

The row says why in words, like "The internet dropped."

1. Check that your computer is connected to the internet.
2. Leave the download where it is. It resumes on its own when the connection is back.
3. If it stays stopped for a long time, close the Stack and open it again. The download starts again from where it stopped.

## If the board shows red

A red tile means one job has stopped, and the row under it says why in words.

1. Read the line under the red tile.
2. If it says a download stopped, fix the internet first.
3. If it says something else, close the Stack and open it again. The board rechecks everything when it starts.

## If the page will not open

1. Close the Stack and open it again.
2. If the page still will not open, check that no other app is using the same port.
3. If it still will not open, the page is on this computer only. Make sure you are on the same computer that runs the Stack.

Still need help? Open the Stack, choose Settings, and check "Check for updates" is switched off if you want nothing to leave at all. The Stack keeps working without it.
