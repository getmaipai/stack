Features / Memory and tiers

Fit your hardware, protect your computer.

A memory guard loads only what fits, and a priority order keeps the work you need most loaded.

Read the Features and models guideGet started

What it does

  • A ready-made setup for each memory size, with what stays loaded and what loads when askedShipped
  • Four levels per feature, Reduced, Standard, Boost and Max, and you choose which model each level usesShipped
  • A model that does not fit your memory is refused, with the reason in a sentenceShipped
  • A priority order, "Which feature goes first", decides who is served first when memory is tightShipped
  • Engines that sit idle unload and free their memoryShipped
