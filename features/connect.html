Features / Connect your apps

One address per job.

Chat, speech, pictures and more answer on one local address in the OpenAI format. Stack picks the engine.

Read the Integration contractGet started

What it does

  • Each job is a role on a standard path, such as chat completions, embeddings, transcription, speech and imagesShipped
  • Every reply says which engine and model answered, in a headerShipped
  • API changes are additive, and the OpenAPI description is generated from the codeShipped
  • Make an app key on the admin page and send it as a standard bearer key to the chat, vision, speech and model-list routes. Keys are scoped, revocable and limited so they cannot slow HomeShipped
